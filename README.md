# Live Dashboard for Power BI

This repository supports a live dashboard for viewing Power BI (PBI) dashboards in a centralized interface.

Features:
- Embed Power BI dashboard visuals
- Display real-time or frequently refreshed metrics
- Provide a single view for key performance indicators
- Help stakeholders monitor business insights quickly

Use this live dashboard to keep dashboards visible, simplify reporting, and stay updated with current PBI data.
